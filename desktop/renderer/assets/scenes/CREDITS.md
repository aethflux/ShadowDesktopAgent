Shadow scene backgrounds
========================

The scene backgrounds in this directory are AI-generated bitmap assets created
for Shadow's desktop companion UI. They are used as local Electron renderer
assets for the console, floating input box, and scene-style picker.

Files:

- `scene-sakura-study.png` — sakura study desk
- `scene-rainy-cafe.png` — rainy cafe workspace
- `scene-neon-studio.png` — neon streamer studio

Generation notes:

- Generated with the built-in image generation path using prompts for anime
  visual-novel style backgrounds.
- No project secrets, API keys, screenshots, or personal files were used as
  source material.
- The images intentionally avoid readable text so the UI can safely layer
  controls over them.
